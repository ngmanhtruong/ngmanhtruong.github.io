# SEO notes

Canonical site: **https://matthewnguyen.vercel.app** (hard-coded in `index.html`, `articles.html`, `article.html`, `robots.txt`, `sitemap.xml`, `llms.txt`, `assets/README.md` and the sync script). If you move to a custom domain, replace it everywhere (`grep -rn matthewnguyen.vercel.app .`).

## What is in place
- Per-page `<title>`, meta description, canonical, robots, Open Graph and Twitter cards; share image `assets/og-image.jpg` (source: `assets/og-source.html`).
- Structured data: `Person` + `WebSite` + `ProfilePage` JSON-LD on the home page, `CollectionPage` on the articles list, and a `BlogPosting` generated per article by `article.html` (title, description, canonical, OG URL are also set per article). Missing articles are marked `noindex`.
- **Static article pages**: `notes/<number>-<slug>.html` are pre-rendered from the GitHub Issues by `.github/scripts/build-notes.mjs` (run by the sync Action on every issue change; locally: `SYNC_OFFLINE=1 node .github/scripts/sync-articles.mjs`). They use `article.html` as the shell and the very same markdown renderer as the browser, carry the full text, canonical, OG and `BlogPosting` JSON-LD, and load less JavaScript than the dynamic page (no `articles.js`). The article list links to them, and `article.html?slug=N` redirects to them (add `&dynamic` to debug the client-side page).
- `robots.txt`, `sitemap.xml` (regenerated by `.github/scripts/sync-articles.mjs` whenever an issue changes) and `llms.txt` for AI crawlers.
- Both `matthewnguyen.vercel.app` and `ngmanhtruong.github.io` serve the site; every page's canonical points to the Vercel URL so they do not compete.

## Do these yourself (cannot be done from the repo)
1. Google Search Console: add the property, verify, submit `https://matthewnguyen.vercel.app/sitemap.xml`, then "Request indexing" for `/` and `/articles.html`. Do the same in Bing Webmaster Tools.
2. Put the site URL on your LinkedIn (Contact info and Featured), the GitHub profile (website field and profile README) and the repository "About" link. Backlinks from these are the cheapest ranking signal.
3. Consider a custom domain (for example `matthewnguyen.dev`) and make it the canonical one.
4. Publish articles regularly; each one is a new page that can rank for a long-tail query.
5. Optional: add a downloadable PDF CV (`assets/cv.pdf`) and link it from the contact section; it matches "resume / CV" searches.

## Realistic targets
Generic words ("portfolio", "resume", "cv", "AI resume") are dominated by templates, builders and big sites; a personal site will not reach page 1-2 for them. Winnable: your name ("Matthew Nguyen developer", "Nguyen Manh Truong"), and long-tail terms such as "senior front-end developer Vietnam", "Vietnam software engineer portfolio", "AI engineer portfolio Vietnam", "context engineering AI-first repo".

## Search Console verification
The home page carries `<meta name="google-site-verification" ...>` (in `index.html`). Verify the URL-prefix property `https://matthewnguyen.vercel.app/` with the "HTML tag" method. The DNS TXT method only works for a domain you control (a custom domain), not for `*.vercel.app`.
