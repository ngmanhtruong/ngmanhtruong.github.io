01About me

A Sr. engineer in the age of AI agents

Agents write code fast. My job is to decide what is worth building and keep it fast, lean and reliable on every screen.

what I do (or did), in a nutshell:

  • Build web apps and landing pages with React, Next.js, Vue and Angular or any frameworks/libraries that fit the project needs.
  • Wrote smart contracts and ship NFT marketplaces. Also metaverse projects.
  • Build SaaS learning portals for organizations around the world.
  • Used to teach kids to code and make games with Scratch.
Building with AI agents

I use AI coding agents every day to draft, refactor, test and review faster, while I stay in charge of architecture, quality and the final call.

Lean on resources

I keep CPU, memory, bandwidth and cloud costs low: ship less code, load only what is needed, and right-size what runs.

Faster page loads

Smaller bundles, code splitting, lazy loading, optimized images and fonts, and smart caching, so pages show up quickly.

Every device

Responsive, touch-friendly layouts that hold up from small phones to wide desktops and across modern browsers.
