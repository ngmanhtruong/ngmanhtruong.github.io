# Project screenshots

Hero screenshots (1280x800 viewport, resized to 640px wide, WebP) shown as a torn-paper photo in the bottom-right corner of the matching card in the Projects section of `index.html` (`.proj-shot` in `css/style.css`).

To add one: save a 16:10 screenshot as `assets/projects/<name>.webp` (about 640x400) and add `has-shot` to the card plus an `<a class="proj-shot">` block like the existing cards.

Supplied by the author (sites not reachable for automated capture): `nanlms.webp` (admin portal), `kbm.webp` (internal KBM).
