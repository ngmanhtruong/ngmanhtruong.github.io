# Assets

- `projects/`: project screenshots (see `projects/README.md`).
- Doodle icons: the article filter tabs, category badges and reaction buttons use hand-drawn SVGs from https://svgdoodles.com (by Mike, Lexington Themes; free to use per the site). They are embedded as `<symbol id="ic-...">` in the `<defs>` of `articles.html` and `article.html` with stroke widths pre-scaled for ~22px rendering. Mapping: ic-grid (wonky-grid, All Notes), ic-bolt (sketchy-lightning-bolt, Technicals), ic-speech (speech-bubble, Opinions), ic-bubbles (bubble-cluster, Random Thoughts), ic-heart (hand-drawn-heart, Loved it), ic-burst (starburst-sparkle, Well said), ic-daisy (loose-daisy, Learned something), ic-question (scribble-question-mark, Not convinced), ic-spiral (dashed-spiral, Lost me).
